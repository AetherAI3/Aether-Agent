# Aether Agent v0.4.0 — source candidate

The candidate adds Cloud managed-agent inventory, creation, customization and
Online DM access to the terminal, followed by guided ATS setup. The ATS adapter
is bundled with exact browser/context dependencies; the paid ATS engine and
Agent Browser runtime remain separate prerequisites.

Browser setup now includes explicit open, status, refresh, stop and retry
controls, draft-preserving terminal updates, validated image receipts and a
read-only visual skill. The SDK adapter bounds stalled/oversized response
bodies and cancels observation during chat cleanup. Native noVNC stays on its
runtime host. Real headed-browser and Cloud model-tool dispatch qualification
remain separate from local fixture results.

The source version is `0.4.0`; this record does not assert a tag, npm/PyPI
publication, production deployment, live account qualification or autonomous
trading. Local fixtures and packed-install checks must remain distinct from
hosted CI and live-service evidence.
