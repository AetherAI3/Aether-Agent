# Aether Agent v4.20.0 release record

October 6, 2026. The owner selected v4.20.0 for the next npm and PyPI release.
Thirty-one commits after the v0.4.0 tag add live task steering, queued command
controls, shell-result review, goal execution, persistent PowerShell, model
picker improvements, and more complete Remote Control and managed-agent status.

The [release notes](../../RELEASE_NOTES.md) describe the user-visible scope.
The [operator packet](OPERATOR-PACKET-v4.20.0.md) tracks exact-source checks,
runner availability, packaging, and publication evidence. The opening entry
recorded a candidate; the publication update follows.

## Publication update

The owner approved a manual release exception after hosted CI and artifact
uploads were blocked by account billing, artifact storage, and private ATSv2
access. The annotated `v4.20.0` tag points to main commit
`020c0cba876ae0dc02f6686de6a2d98e95f398fb`. npm
`aether-agents@4.20.0` is published and its public registry SHA-1 matches the
reviewed manual tarball (`43c6875a51e06e9b6f41385c93b981c092156cdf`).
The npm package lacks the usual GitHub-hosted provenance attestation.

The GitHub Release remains a draft while PyPI `aether-agent==4.20.0` awaits
its protected upload. The existing PyPI trusted publisher is tied to the
repository's original lowercase name, which has been restored. The status of
the npm and PyPI registries, the GitHub release, and the remaining gates is
tracked in the [operator packet](OPERATOR-PACKET-v4.20.0.md).
