authorized a one-time self-hosted release exception to avoid GitHub-hosted
runner use. This file begins as a source-candidate record. A tag, registry
publication, and final package digest remain pending.

and one Windows. Recent main CI runs failed functional tests and GitHub

or an explicit, recorded qualification limit before publication.
