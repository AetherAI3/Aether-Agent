# 2026-09-27 — v0.4.0 interactive chat qualification update

This is a candidate and incident record, not a v0.4.0 release announcement.
At 20:58 UTC, npm `aether-agents` `latest` was 0.3.2 while the repository
manifest was 0.4.0. An installed 0.3.2 interactive chat from a broad Windows
home directory (`%USERPROFILE%`) was reported to accept a prompt without
answering; a one-shot chat from a small project directory returned an answer.
Reauthentication did not resolve the home-directory symptom.

The source-candidate [operator packet](OPERATOR-PACKET-v0.4.0.md#2026-09-27-interactive-chat-incident-gate)
records the exact `main` head, merged packed-401 regression coverage, the
merged home-folder discovery and SSE integrity fixes, and the separate
installed-package and live-account gates. No v0.4.0 tag or publication is
established by this entry.
