This package contains the runtime-only files from qrcode-terminal 0.12.0
(https://github.com/gtanner/qrcode-terminal), licensed under Apache-2.0.
The vendored QRCode implementation is by Kazuhiko Arase, copyright 2009,
licensed under MIT. Its source notices are preserved.

The Aether workspace package name and manifest are local. Examples, tests,
command-line entry points and packaging metadata from the upstream package are
omitted; the QR generation algorithm and renderer are unchanged.
